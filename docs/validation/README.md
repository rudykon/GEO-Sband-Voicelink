## 完整仿真

默认链路和自定义 RF 器件对比均启用 Simulink、图表与报告，计时覆盖外部命令启动到退出。

| 配置 | 完整耗时 | 进程树私有内存峰值 |
|---|---:|---:|
| 默认整链 | 65.37 秒 | 3.88 GiB |
| 自定义 RF 器件与默认基线 | 65.49 秒 | 3.87 GiB |

两次运行均通过 600 秒、8 GiB 上限及产物完整性检查。每次 Simulink 检查覆盖 15 组场景/速率、22500 帧，决策差异为 0。

默认模型采用 8 个原生模块。自定义器件示例采用 7 个原生模块和 1 个 MATLAB 适配器；适配器检查接口及串接，算法由 MATLAB 实现执行。

自定义器件对比使用全部 90000 个配对帧：改善 3243 帧、退化 0 帧、保持不变 86757 帧。15 组结果均满足前向时延增加 5 ms、返回时延不变。

每个配置测量一次，耗时会随启动缓存和系统负载变化。默认参数为工程假设，结果用于总体设计与方案对比。

## 源码包检查

测试和完整仿真使用源码 ZIP 解压出的独立目录。源文件在运行后保持不变，运行产物和 Simulink 缓存写入 artifacts。导出时检查文件清单、文档链接、凭据模式和 ZIP 内逐文件 SHA-256。

运行入口见[首页](../../README.md)，模块合同见[开发指南](../module_development.md)，导出命令见[GitHub 准备](../github.md)。
